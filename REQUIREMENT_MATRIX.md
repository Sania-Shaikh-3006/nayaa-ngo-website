# Requirement-to-feature matrix

| Requirement | Implementation |
|---|---|
| Home | Home page with mission, vision, programs, stats, stories, campaigns/projects |
| About Us | Mission, vision, history placeholder requiring verified milestones |
| Our Work | Education, healthcare, livelihood program model |
| Infographics | ImpactStat model and dashboard cards; upload/expand in CMS |
| Projects | Project model, list/detail, goals, beneficiaries, timeline, location, reports |
| Media | MediaItem, PressRelease, ElectronicMedia |
| Get Involved | Volunteer, Partner, Fundraise, Campaigns, Community, Donate |
| Blog | BlogPost list/detail |
| Contact | Form, office map area, contact information placeholder |
| Donations | Amount/frequency/project/program/gateway selection and receipt flow scaffold |
| Responsive UI | Bootstrap + mobile-first CSS |
| Accessibility | semantic sections, labels, skip link, alt text |
| CMS | Django admin for database content |
| Role-based access | Django authentication foundation; add Groups/Permissions for staff roles |
| Security | Django CSRF/auth, environment secrets, payment keys outside source code |
| Analytics | Dashboard counters and donation totals; external analytics can be added |
| Multilingual | Django i18n enabled for English/Hindi |
| SEO | title/meta, sitemap, readable URLs |
| REST API | Django REST Framework endpoints |
| MySQL | MySQL/PyMySQL configuration when DB_NAME is set |
| GitHub | README and module-by-module push checklist |
| Deployment | deployment checklist and static/media configuration |
| Login | login, logout, registration, password reset |
